## Blog Api Admin Frontned

Blog Api Admin frontend is vite + react project created to consume my first API. This website is built with react and allows admin to create, publish, edit and delete blog posts.
It also allows admin to delete comments left by other users.
I've decided to use TinyMCE to create blog posts to allow for much nicer looking posts that can have a lot of customization. 

### Built with

- Vite
- React
- React router
- TinyMCE
